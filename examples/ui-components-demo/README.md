# UI Components Demo

This directory contains working examples of the Modal, Tabs, and Dropdown components from the Web Agent Framework.

## Examples

### 1. Modal Component (`modal-example.tsx`)

Demonstrates:
- Basic modal usage
- Different sizes (small, medium, large, fullscreen)
- Custom actions
- Close behaviors
- Nested content

### 2. Tabs Component (`tabs-example.tsx`)

Demonstrates:
- Horizontal and vertical tabs
- Icons in tabs
- Disabled tabs
- Dynamic content
- State management

### 3. Dropdown Component (`dropdown-example.tsx`)

Demonstrates:
- Basic dropdown
- Options with icons
- Disabled options
- Dividers
- Selected state

### 4. Combined Example (`combined-example.tsx`)

Demonstrates:
- All components working together
- Real-world use case (settings panel)
- Complex interactions

## Running the Examples

```bash
# Install dependencies
pnpm install

# Run the dev server
pnpm dev

# Open http://localhost:3000
```
